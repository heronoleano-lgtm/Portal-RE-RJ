# ADR 0005 – Cruzamento de bases com regras de prudência
**Decisão:** identificar processos pelo número (DJEN/editais), enriquecer pelo DataJud e ligar partes por CNPJ, sem presumir papéis:
devedora só pelo cabeçalho do edital; demais CNPJs como "citados"; pessoa física sem nome gravado.
**Consequências:** menos cobertura de devedoras, porém sem atribuições incorretas; a regra é exibida na página "Como coletamos".
